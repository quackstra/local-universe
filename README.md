## The Big Number

### **~730 – 6,100 net-new Radix TPS at movement scale (T3)**

15–120× Radix Babylon's live ~50 DeFi TPS. Supporting: **~$0.65–6.2T** tokenizable local
resources · **~$18–190B/yr** retained locally · **~$0.5–1.5B/yr** XRD burned. Live dashboard:
[**quackstra.github.io/local-universe**](https://quackstra.github.io/local-universe/).

## The Six Ventures (from the source theses)

1. **SBI / ScryptDole** — unbacked Social Basic Income token (100/mo/verified person)
2. **SRU** — Securitized Rental Units (renters accrue equity per rent payment)
3. **DAO–JOBS** — the DAO ↔ Reg-CF crowdfunding compliance bridge
4. **Business Ops** — on-ledger payroll / inventory / payments / royalty splits
5. **CCS** — Complementary Currency Systems (BerkShares-style, badge-gated fees)
6. **RUBIS** — Radix Universal Basic Income Systems (local, unbacked)
